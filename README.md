# Wellness Marketplace for Alternative Therapies

A full-stack web application that connects users with certified alternative therapy practitioners.  
The platform allows users to browse therapy sessions, book appointments, and manage their wellness journey.

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- REST APIs

### Database
- MySQL

---

# Milestones

## Milestone 1 – Practitioner & User Profiles

### Features
- User Registration and Login with JWT authentication
- Practitioner verification and specialization tagging
- User dashboard with session history and product orders

### Outcome
- Login / Register forms
- Profile setup page
- Practitioner verification module

---

## Milestone 2 – Therapy Booking & Scheduling

### Features
- Browse and book therapy sessions
- Calendar integration for selecting therapy session dates
- Session reminders for scheduled appointments

### Outcome
- Booking form
- Calendar widget
- Session detail page displaying therapy information
