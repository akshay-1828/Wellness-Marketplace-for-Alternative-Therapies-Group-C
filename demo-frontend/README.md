# Wellness Marketplace for Alternative Therapies

## Project Description
This project is a wellness marketplace platform where users can explore alternative therapies, book sessions with practitioners, and manage their therapy schedules.

---

## Tech Stack

Frontend
- React
- Tailwind CSS
- Axios

Backend
- Spring Boot
- Java

Database
- MySQL

Authentication
- JWT (JSON Web Token)

---

## Milestones

### Milestone 1: Week 1–2 – Practitioner & User Profiles

Features:
- Registration and login with JWT authentication
- Practitioner verification and specialization tagging
- User dashboard with session history and product orders

Outcome:
- Login/Register form
- Profile setup page
- Practitioner verification module

---

### Milestone 2: Week 3–4 – Therapy Booking & Scheduling

Features:
- Browse and book therapy sessions
- Calendar integration and session reminders

Outcome:
- Booking form
- Calendar widget
- Session detail page
